CAFECITO - Proyectito (Android Studio, Kotlin + Jetpack Compose)

ANTES DE EJECUTAR
1. Firebase: crea un proyecto en https://console.firebase.google.com, agrega una app Android
   con el package  com.example.proyectito , activa Authentication > Correo/contraseña y
   descarga google-services.json. Colocalo en:  Proyectito/app/google-services.json
2. Google Maps: en local.properties (raiz del proyecto) agrega una linea:
       MAPS_API_KEY=tu_clave_de_Maps_SDK_for_Android
   (Android Studio ya crea local.properties con sdk.dir; solo agrega la linea.)
3. File > Sync Project with Gradle Files, y ejecuta.

ARQUITECTURA (MVVM)
  data/local        -> Room: entidades, DAOs, AppDatabase
  data/repository   -> CafeRepository (unica fuente de datos) + datos iniciales
  viewmodel         -> Auth, Menu, Carrito, Mapa, Perfil
  ui/screens        -> pantallas Compose (solo observan el estado del ViewModel)
  navigation        -> rutas, NavHost y menu inferior
